# S1　岛上，人渐渐过成了人 —— E13

@node ch3_s0_router
登上这座岛的第七天。清晨六时三十分，会客厅。长桌、煎蛋、牛奶、那份琥珀色果酱。我已经能准确知道每份摆在谁面前——可可那份果酱总要多挖一勺，汉娜那杯牛奶总会被她放凉一半再皱着眉一口闷掉。日子就这样一天一天过成了"日子"。
汉娜把旧窗帘拆了改成一幅熨得平平的桌布，又给医务室窗台缝了个装野花干的小布袋。雪莉的"岛志"悄悄厚了一圈，她记谁几点醒来、谁几天没笑过、哪桌饭菜剩多少。梅露露的茶还一杯一杯地递，给玛格的照旧放窗口，玛格照旧学会不推回来，但也不接。
安安迷上"破译"这件事——"这座岛为什么要把人安顿得这么好？没有树，没有坏人，连晚上熄灯都有人替我们换灯。这么好，好得反常。"她眯起眼，"反常的东西，要不是藏着什么，就是在等什么。"
直到那天傍晚。我路过会客厅后门，正撞见守夜的守卫拖着它老旧却笔直的身躯，在东侧围墙根下慢慢地踱，比平日更缓慢、更拘谨，像在确认什么东西存在，又像在躲避。它走到墙根忽然停下，抬着那具看不清脸的面孔，朝着墙外那个方向定定地站了很久，在暮色里站成一道很长的影子。
我站在门柱后面没敢出声。等它转身拖着步子离开时，我心里咯噔了一下——那座一直如钟表般准时的守卫，那一刻看起来，几乎像一个……在害怕什么的东西。

# S2　希罗的，一道裂缝 —— E14
# --------------------------------------------------
@node ch3_shiro
数日前，我在她门外撞见她独自对着月光说话之后，希罗似乎更沉默了。她几乎不参加夜间的围坐，安安静静地来，安安静静地走。但有一件事让我放心不下。
那天晚上熄灯前，我透过没关严的门缝，看见希罗房里没有开灯。她背对着门坐在窗台上，手里握着那支钢笔——不是转，是握着，指节微微泛白，像在用力克制着什么。
"……你知道吗，"她说，像在对一个不存在的人说话，"我以为我把它——把你，忘在这里，就能把'她的死'也忘在这里。可我不行。"
月光把她的影子压得很扁。"他们都说，那个人不是真的。他们说，这座岛上，从来没有过那样一个孩子。可我——我记得。我记得她的气味，记得她逗我笑的样子，记得她……把笔塞进我手里那天，湖边，没有风。"她停住，抬起手背极快地擦了一下脸，"可如果，连我都不记得她了……那她，就真的，哪里都不在了。"
我站在门外，脚像被钉住。我忽然明白——希罗不是"放不下一个梦"，她是坚持地、固执地、哪怕全世界都说没有这个人，也要独自记住一个人。她扛着的不是一个名字，是一场"如果连我都不记得，就再也没人记得"的、漫长的、一个人的守护。
我本想说点什么。可最后我只是轻轻替她把门掩上，为的是让她知道，或许她不用一个人扛那么久。门掩上的瞬间，我听见房里极轻极轻地传来一声不像哭泣、却比哭泣更响的"我……"——我没有推门进去，只在走廊里站了很久。

# S3　第三次，窗前那只杯子 —— E15

@node ch3_meruru
这几天，梅露露送玛格的那杯茶一直放在窗台上，没有推回去，也没有被喝。就那样，一杯，凉了，又被悄悄换掉，再放一杯新的。
我问梅露露："她一直不接，你还一直放？"她低着头，往新茶边缘又转了一圈握柄："……要的。因为她已经开始不把我放的茶推回去了。推回来，是怕欠我；不推回来，是她开始愿意试着接一下了。只是她还没决定，敢不敢喝。"
那天傍晚我陪梅露露去放今天的茶，意外撞见了玛格。茶还没放上去，她就已经等在那里。她捻着牌没抬头，声音比以往任何一个时候都软了一丝："……你放了好几天了。""嗯。""梅露露轻轻把茶放上去，"等你喝。"
玛格的手指在牌面上停了停。过了很久，她很轻地说了句什么。我刚要听清，她却已经把那杯茶端起来——没喝，只是端在手里，看着杯沿，像在看一件很陌生、又很暖的东西。
梅露露的眼眶忽然红了。她没哭，只是低下头，极用力地眨了一下。那天那杯茶，玛格没有推回去，也没有喝，只是端了很久很久。

# S4　气球，牵了绳 —— E16
# --------------------------------------------------
@node ch3_noah
墙根下那幅画又变了。气球画好了，绳子握在一只手里。只是那只手旁边，多了另一只手，从画外伸进来，虚虚地将绳子的一截接在自己指尖。两只手隔着一段极短的空白，像随时可以握住，又像还差那么一点点就能真的牵住。
诺亚蹲在墙前，没有再画新的气球，只是伸手，用指尖替那只画里的手轻轻勾住那截绳子。"……她画了三次。三次都没有越界，"她的声音闷闷的，"每一次伸手都停在'刚好够到'的地方，等诺亚，等诺亚这边也伸出手。"她停了很久，才用一种我怕惊动谁的声音说："诺亚……诺亚想试一下了。"
远处蕾雅正朝这边走来，在她习惯的距离停住。这一次，诺亚没有低头。她抬头，朝蕾雅轻轻地伸出了一只手——不是去够什么，只是伸出来，悬在半空，像那颗气球终于肯把绳子交出去一半。
蕾雅怔住了，过了好几秒才像被什么推着似的，慢慢地朝那只手伸出自己的手。墙根下，两颗被各自藏着的心，终于隔着一点点距离，轻轻地相触了一下。
我悄悄退开几步，不忍打搅。可心里却涌上一阵说不清的酸楚——因为这岛上，有太多人一辈子都在等这样一只手，却也许，永远等不到。

# S5　没有响的雷 —— E17
# --------------------------------------------------
@node ch3_thunder
第七天夜里，异样变得清晰。先是汉娜缝在窗台的小布袋破了，第二天一早就找不到了。然后是守夜的守卫——那晚它巡视的步子比往常更缓慢，停在哪扇门前也停得更久，有时站在某扇门前却迟迟不走，像在确认什么，又像在犹豫什么。
最让我不安的，发生在凌晨。我起夜路过走廊，那盏新换好的壁灯没有闪。可当我经过时，它忽然极轻地闪了一下——不是坏，是像被什么掠过，光一暗，又一明。我一愣，抬头去看，什么都没有。可紧接着我听见走廊那头的守夜守卫，发出了一声极轻极轻的、几乎不像它该有的声音——像一声叹息。
我僵在原地。那声叹息转瞬即逝。之后一切如常，守卫继续它笔直的巡视，仿佛什么都没发生过。
可那一刻我清清楚楚地感觉，这座岛上有什么东西，正在极慢极慢地，从"日常"的平层底下，往上拱。我想起雪莉本子里那句"遇之，勿近，勿言，勿视"——那行字要守的东西，大概早在我看见它之前，就已经不是我能轻易名状的了。而守卫那声叹息，不像是在为我守着夜，倒更像是在替这岛上正在裂开、而我还没有资格看清的另一条缝，提前叹的气。
回到房里躺下，窗外月亮在云里忽明忽暗。我久久没睡，听着守夜的脚步声，像在听一座岛，正一件一件，把它们藏了很久的东西，慢慢地醒过来。

# S6　最后一个，安静的早晨（第三章收束·goto 第四章）
# --------------------------------------------------
@node ch3_morning
第八天清晨。岛上没有树，晨光还是从没被树叶遮挡的天直直照下来。昨夜整夜无人失踪、无人受伤、无人寻事。可我知道这就是那个"最奢侈的、平静的早晨"了。
我推开窗，看见窗台上不知什么时候多了一小截橘色的粉笔，旁边压着一张字条，字迹软软怯怯："《～气球的绳，我先牵一半。另一半，埋在墙根最底下那格砖缝里。等到该埋的时候，你替她画上。》"是诺亚。我捏着那截粉笔，一时说不出话。
窗台另一头，昨晚那杯茶旁多了一小张手写的签纸，墨迹很新："《这一签，我替她留着了。——玛格》"。我不知道"她"是指谁，但我知道，这座岛上已经有人在试着替别人留一点东西了。
我站在晨光里，忽然觉得这段日子——这段我以为会永远静下去的日常——其实早在我没注意的地方，一点一点织成了一张密密的网。网上的每一根丝，都是一个人曾经小心翼翼地，向另一个人伸出手的痕迹。而暴风雨不是要"打破"这张网，它只是要趁这张网织得最密的时候，轻轻一拉，看它能不能兜得住这十三个人。
我听见会客厅的钟发出一声轻响。我深吸一口气，把那截粉笔揣进口袋，朝会客厅走去。日子还要过下去。而第四章，已经站在门外了。
