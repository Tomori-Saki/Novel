# S1　薄暗之笼，未至的清晨 —— 地下苏醒与十三人
# --------------------------------------------------
@node s0_breakfast
本该是高中一年级开学典礼的早晨。可当我睁开双眼时，视野里没有晨光，没有熟悉的天花板，只有一片阴冷陌生的昏暗。后脑勺残留着轻微的眩晕与钝痛，身下是一张铺着粗布床垫的简陋单人木床。借着高处采光窗漏下的微弱灰光，我才看清自己身处一间狭小局促的地下小房间——四面是厚重的石壁，正前方的厚实木门紧紧闭锁着。
身旁散落着我原本准备背去高中的书包与准考证，没有任何被袭击或绑架的记忆。
隔壁房间随即传来女声用力拍门的惊慌大喊："喂……有人吗？！开门啊！这是什么整人节目吗？！人家今天还要去新学校报到啊！"另一侧较远的房间里，传来一个沙哑干脆、略带不耐烦的成熟嗓音冷冷打断："太吵了。省点力气吧，小姑娘。门是从外面锁死的，骨头撞断了也撞不开的。"
整条原本死寂的地下走廊仿佛被逐一唤醒，隔着木门，惊呼声与困惑声此起彼伏：有人在轻声作着柔和的祷告；隔壁则是双手叉腰、元气脱线地嚷嚷着"名侦探雪莉的脱出大推理开幕"并伴随着差点拧断门把手的可怕怪力巨响；而走廊最深处的房间里却死寂一片，只有缩在床角抱紧速写本的瘦小自闭少女，连呼吸都屏得微不可闻。我们一共有十三个人，全被关在相邻的房间里。
踏、踏、踏。缓慢平稳的脚步声自石阶高处传来。从阴影中走出的，是一个身着严谨燕尾服、却长着猫头鹰面容的使魔身影。
"早安，诸位尊贵的客人。"管家尖细而平板地宣布，"欢迎来到与世隔绝的孤岛，以及这座建于数百年前的牢屋敷。诸位为何出现在此不必探寻，出岛的途径并不存在。为了保障各位作为少女最基本的生活体面与起居尊严，地下居室均已配备独立木门、寝具与案几。每日早六时至晚二十二时放风自由活动。请各位整理仪容，清晨六时三十分，会客厅集合，彼此相识。"
连续十三声清脆的锁簧弹开声在走廊两侧接连爆开，紧锁的木门微微开了一条门缝。阳光从几十级台阶之上的玄关大厅远远洒下一片惨白的亮斑。我们十三名彼此尚不知晓姓名的少女，就这样毫无预兆地被扔进了一场不知归期的封闭生活。

# --------------------------------------------------
# S2　地下的第一个黄昏 —— 香草茶与守夜
# --------------------------------------------------
@node ch1_night
监房在地下一层，靠东的一排。门都是规整的木门，门牌手写，字迹软软糯糯。管家早先那句话还在耳边回响："夜里落锁，诸位从门里进出——总归留着最基本的体面。"
我推开自己的房门，里面有一张铺着单薄床垫的单人床、木柜与小桌椅。桌角放着一只空杯子，和一小包用纸卷着的散装花叶。纸角压着软软的小字："《冰上梅露露，拜访——读，初来乍到，各屋都放了一包自己晒的香草茶。不合口味就告诉我，明天给你换别样的。睡个甜觉呀。》"
我去拧了拧对门的房门，门内桌上同样摆着那只杯子和同一包香草茶。我心里忽然软了一下——那个叫梅露露的女孩，挨着每一扇门，都悄悄放了一包茶，又悄悄离开，给每个人，都留了一句"睡个甜觉"。
夜间，守夜开始了。灯火暗下去，我躺在木床上，听见很轻的脚步声，从走廊这头踱到那头，再踱回来。那不是人——人的脚步不会这么均匀。是守卫。掩着的门缝底下，掠过一道长而直的黑影，一步一停，像在确认每一扇门都还关着。
第二天清晨，走廊里那张可可半夜偷偷贴出的、画着鬼脸写着"巡查辛苦♪——可我们也是会害怕的生物呀"的俏皮便条不见了。守夜，却真的悄悄地轻了下去。
那晚我睡得很浅。隔壁传来可可压低嗓子讲笑话的声音，再隔一间，有人轻轻哼一首歌，调子软软的，一遍一遍哄着走廊入睡。那首歌我后来听过很多很多遍，全岛都会哼，管它叫"幽灵歌"。
我翻了个身，只反复记着一句话——管家说，在这里，我们"可以把日子，过成任何愿意过的日子"。我不知道那是真的，还是一句让笼中鸟安静下来的好听话。但我愿意，先试着相信它是真的。

# S3　晨间的会客厅，七条规矩 —— 早餐与 E02

@node ch1_s3
铛——铛——铛！走廊高处的黄铜挂钟沉闷鸣响，众人陆续走出房间来到会客厅。长桌擦得雪亮，摆着十三份早餐，牛奶、煎蛋、烤得酥脆的面包，还有一小碟岛上自产的琥珀色果酱。
管家站在晨光里宣布七条日常作息：早六时半早餐；其余放风时段；换洗衣物丢入滑槽周一焚烧；二十二时宵禁禁语；禁止进入地下焊死铁门；禁止翻越西侧围墙；図書室借阅与中庭；若遇上解决不了的事，敲响会客厅袖钟。
可可第一个追问"别人也解决不了的事呢？"管家目光微扫，轻声答道："那么——就是它们来解决的事了。"
我数了数长桌：十三人坐满，却隔阂重重。橘雪莉双手叉腰、斗志昂扬地宣布自己这位"名侦探Crusher"必将以华丽推理脱出，结果一巴掌差点把托盘拍裂；玛格指尖捻着塔罗牌，眼神如狡黠狐狸般直勾勾盯着我，轻佻调笑道："小艾玛这么盯着人家，是想听占卜，还是想让姐姐教你一点成年人的秘密游戏？"纤细指尖在锁骨划过；而安安缩在最边角，一声不吭地推来写着《此岛足有十三头胆小鬼》的速写本。
晨光泼进会客厅。桌尾的希罗面前那杯早茶一口没动，低头转着磨损的钢笔，始终不愿去接那束光。
我从那杯凉掉的茶上，移开了目光。

# S4　希罗，读的那支笔 —— E03
# --------------------------------------------------
@node ch1_shiro
早餐后，我折回地下监房。希罗的门，关着。我敲了两下没有动静，第三下门从里面拉开——她站在门缝里，黑发披着，眼神却清醒得不像刚醒。
"……有事？""早安。刚才在上面，你一句话也没说，有点担心。""我在休息。谢谢。"门要合上。
我那句"早安"卡在喉咙里，不甘心地追了一步："刚才在会客厅，你一直在看窗外那片湖——"希罗按着门框的指节微微僵住。她回过头看我，眼神平得像一潭结冰的水，可冰面底下有什么东西动了一下。
"——你在看什么？"我问。走廊里静默得很响。
希罗垂下眼，胸前口袋里那支钢笔反了一下光。我以为她要发火或关门，可她只是很轻地说："我没有在看外面的湖。"她转身把门合上，合拢的瞬间，咬字很轻，像不是对我说，而是对某一个不在场的人，"……她不喜欢那片湖。"
我站在走廊里，愣住了。那句"她"——到底是谁？一个"不喜欢那片湖"的、从没在这条走廊里出现过的人。
下午，庭院里三五成群。希罗没跟任何人说话，一个人坐在会客厅门侧的长椅上，手里横放着那支钢笔，用指腹一点一点抚过笔杆，像在抚一件很旧很旧的东西。她低着头，刘海遮住了大半张脸。
那一刻我心里冒出一个不该有的念头：这支笔，是不是替她装着一个她没法放下、谁也没有见过的人？这个念头，后来在很久很久以后被证实了。只是证实的方式，不在我今天能想到的尽头。

# S5　三十杯茶，和一杯没人要的 —— E04
# --------------------------------------------------
@node ch1_meruru
午后，医务室里，旧水壶呼噜噜响着。她系着素色围裙，正在给我们泡茶："是香草茶，加了岛上的薄荷和一点点蜂蜜。可可酱等下还要跟亚里沙酱拌嘴呢，喝甜一点，心情会好哦。"
梅露露的笑声脆生生的，像风铃。她挨个给我们续茶，轮到希罗时，希罗只接过去，端在手里，没喝。梅露露没追问，只是把杯沿朝她转了半圈："希罗酱，握这里，不烫。"希罗的动作顿了一下，很轻地"嗯"了一声，把那杯茶接得更稳了些。
我端着茶看着这一幕，忽然想：梅露露像是把岛上每个人"漏水的地方"都仔仔细细看了一遍。可有那么一个人，是她的那份好递不过去的——那个人，是玛格。
玛格坐在最靠窗的矮凳上，捻着牌，像没在听一屋子动静。梅露露端着热茶蹲到她身边，声音放得很软："玛格酱，这一杯我少放了些蜂蜜——你上次说太甜了，我记得。趁热喝吧。"
窗边空气静了一瞬。玛格没有回头，过了好几秒才开口："……谁跟你说，我不爱吃甜的。"
"你上次在我屋里亲口说的呀。"梅露露说得理所当然，"你还说'甜的东西会把心事也捂化了'——所以我调淡了一点，给你留着心思，不好吗？"
玛格终于转过头来，那双一贯漫不经心的眼睛里有什么东西尖锐地闪了一下。"梅露露，你这个人……"她没把话说完，站起来，把那杯茶轻轻推回梅露露手边，"……我不喝别人替我惦记的茶。好意这种东西，会越滚越大，最后把你整个人都吞了。你趁早收着点，别谁都递。"
屋里安静得有些僵硬。梅露露端着被推回来的茶愣在原地，两秒后"啊"了一声，柔柔地笑笑，把茶端回水壶边倒掉："玛格酱的茶，要留着，下次再泡。"
傍晚，我透过半掩的窗看见梅露露背对着门站在窗前，手里端着那杯被玛格推回来的茶。她没有倒掉，就那样端着，对着窗外那片暗下去的湖，静静地看。晚风吹起她额前的一缕碎发，她的侧脸安静得，像一幅还没来得及落泪的画。

# S6　墙根下，一颗没吹起来的气球 —— E05
# --------------------------------------------------
@node ch1_noah
日头偏西，庭院尽头的墙根拉出长长的影子。诺亚蹲在墙下，捏着一截不知哪捡来的粉笔，一笔一笔在墙上画一颗气球——圆圆的，鼓鼓的。这笔触其实有点笨：弧度收得不稳，手一抖就会出界，她却固执地一点一点描，像是生怕画得不够好，又像是生怕画得太好。
"……好看吗？"她没回头，声音很低。"好看，"我说，"比它旁边那几道发直的线强多了。"那是我能想到的、最不伤她的一句真话——因为那几道线，真的是她手抖画坏的。
"～它的手呢？"她还是没回头，粉笔尖停在气球下面那片空白，"气球的绳，得有手牵着。不然它飞上天，没人接，会飘到——没有名字的地方去。"
我静静站着。就在这时，背后传来轻微脚步声，是蕾雅。她停在几步外的草地边，像被什么牵住似的看着诺亚的背影，没有走近，只在原地有点局促地拢了拢头发——那副样子我认得，是那种"想靠近，又怕惊动"的神情。
她站了很久，末了从口袋里掏出一小卷叠得平平的、干净的纸，轻轻放在草坪边沿那块砖上，然后像怕被人看见似的，转身快步走开了。
诺亚的笔停了。她偏过头，看向那块砖上的纸卷，看了很久很久。"……给没有的手，"她低声说，"……留的。"她没有去拿，只是低下头，在气球旁边多画了一笔——一根从小纸卷里伸出来的、看不真切的手，线条很轻，像连她自己都不确定那算不算一只手。
我没有揭穿她，只在夜风里把那卷纸的位置记进心里。夜色把整面墙盖住。经过那块砖时，诺亚停了一瞬，然后弯下腰，把那卷纸捡起来揣进怀里，没拆。"～谨慎的美德，"她嘀咕了一句，"……先记着。"
我目送她的背影消失在暮色里，低头看见墙角还留着那颗气球的影子——圆圆的一圈，像一只还没来得及被吹起来的气。
