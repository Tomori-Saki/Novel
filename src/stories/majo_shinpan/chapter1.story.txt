# --------------------------------------------------
# S1　薄暗之笼，未至的清晨
# --------------------------------------------------
@node s0_breakfast
本该是高中一年级开学典礼的早晨。可当我睁开双眼，视野里没有晨光，没有熟悉的天花板，只有阴冷陌生的昏暗。后脑勺残留钝痛与眩晕，身下是铺着粗布床垫的简陋木床。借着采光窗漏下的灰光，我才看清——不足十平米的地下小房间，石砌四壁，正前方是一扇厚实闭锁的木门。我被锁在这里了。
没有被袭击的记忆，中间过程一片空白。书包、准考证和学生手册散在床头，连妈妈给的苹果果酱都完好无损——像被从现实世界切下一块，扔进这座地下牢屋。
隔壁传来尖细慌张的女声用力拍门："喂……有人吗？！开门啊！这是什么整人节目吗？！"稍远处，一个沙哑不耐烦的嗓音冷冷打断："太吵了。省点力气吧，小姑娘。门是从外面锁死的，骨头砸断了也撞不开的。"
整条走廊被逐一唤醒：有人轻声作修女般的祷告；有人元气脱线地嚷嚷"名侦探雪莉的脱出大推理开幕"，伴随着差点拧断门把手的巨响；最深处的房间却死寂一片，只有缩在床角抱紧速写本的瘦小身影，连呼吸都屏得微不可闻。算上我这间，似乎有十三个互相紧挨着的房间。
手机忽然剧烈震动——嗡——嗡——！屏幕亮着，没有信号，通知栏弹出带血红感叹号的系统通知：【请全体入居者于五分钟内前往一层会客厅集合。迟到者视作违规。——牢屋敷管理处】
喀哒！正前方门锁簧自动弹开，木门缓缓向外推开一条缝。我深吸一口气，抓着手机试探推门。走廊昏暗，其他房间的门也陆续推开，神色慌张的少女们探出头来，一同沿石阶登上一层的会客厅。
会客厅极其宽敞古旧，中央摆着足以容纳所有人的巨大长木桌。阳光从拱形玻璃窗斜射进来。十三名少女彼此拉开距离，僵硬地围在长桌旁。
扑棱棱——！高窗缝隙中猛地钻进一道灰褐色身影——足有半米高的纯粹猫头鹰！它盘旋半圈，落在长桌正中央椅背上，琥珀色大瞳盯着我们，鸟喙一张一合，吐出地道而倦意满满的成熟男声："啊——咳咳。测试，麦克风测试……好了。各位新来的麻烦制造者们，早上好。"
"哇啊啊啊？！猫头鹰在说人话？！"可可吓得直接蹦到椅子后面。
"请勿大呼小叫。"猫头鹰使魔用翅膀扶了扶额头，"鄙人是这座牢屋敷的管理者——称呼在下'管家'即可。诸位为何在此、何时能回家——一概不知，多说一个字也不算加班费。"
它扫视一圈，像背诵公司章程般宣读保命红线：每日放风时段为早六至十时、正午十二至十五时、傍晚十七至二十二时，其余时间须留地下居室；换洗衣物晚间送入淋浴房滑槽，每周一焚烧；二十二时全馆熄灯宵禁；集体抗议、策划逃跑、破坏公物属严重违规。
"只要各位老老实实遵守手机里的规则，这里就是安全的避难所。鄙人最大的愿望是准点打卡下班——所以，请不要给在下找麻烦，明白了吗？"
说完它双爪一蹬，振翅钻出窗外，只留下一根缓缓飘落的灰褐色羽毛。众人下意识掏出手机——界面上多了三个系统图标：【生活规则】、【作息日程表】与【洋宅立体地图】。
"开什么玩笑啊……"亚里沙透过黑口罩咬牙切齿，"被一只长翅膀的鸟给训话了？"
晨光泼洒在冰冷的长桌上。我们十三个人，在一只满腹牢骚的社畜猫头鹰和一部没有外部信号的手机面前，正式开始了这场不可思议的禁锢日常。

# --------------------------------------------------
# S2　旧墙里的，第一个黄昏
# --------------------------------------------------
@node ch1_night
监房在地下一层，靠东的一排。门都是规整的木门，门牌手写，字迹软软糯糯。管家早先那句话还在耳边回响："夜里落锁，诸位从门里进出——总归留着最基本的体面。"
我推开自己的房门，桌角放着一只空杯子和一小包用纸卷着的散装花叶。纸角压着软软的小字："《冰上梅露露，拜访——读，初来乍到，各屋都放了一包自己晒的香草茶。不合口味就告诉我，明天给你换别样的。睡个甜觉呀。》"
我没急着拆，先去拧了拧对门希罗的门——没锁，推开了缝。门内桌上，同样摆着那只杯子和同一包香草茶。我心里忽然软了一下：那个叫梅露露的女孩，挨着每一扇门都悄悄放了一包茶，给每个人留了一句"睡个甜觉"。
夜间，守夜开始了。灯火暗下去，我听见很轻的脚步声，从走廊这头踱到那头，再踱回来——均匀得像节拍器，是守卫。门缝底下掠过一道长而直的黑影，一步一停，像在确认每一扇门都还关着。
可可夜里偷偷溜出来，在某扇门外贴了画着吐舌鬼脸的便条："巡查辛苦♪——可我们也是会害怕的生物呀，能不能……轻一点呢？"第二天清晨，便条不见了。守夜，却真的悄悄地轻了下去。
那晚我睡得很浅。隔壁可可压低嗓子讲笑话，再隔一间有人轻轻哼歌，调子软软的，一遍一遍哄着走廊入睡——那首歌我后来听过很多很多遍，全岛都会哼，管它叫"幽灵歌"，是梅露露教给大家的。
我翻了个身，只反复记着一句话——管家说，在这里，我们"可以把日子，过成任何愿意过的日子"。我不知道那是真的，还是一句让笼中鸟安静下来的好听话。但我愿意，先试着相信它是真的。

# --------------------------------------------------
# S3　晨间的会客厅，长桌与手机
# --------------------------------------------------
@node ch1_s3
叮咚——！走廊里手机几乎同时响起晨间闹铃，提醒六时三十分早餐放风时段已开启。伴随着可可元气满满的呼喊，众人沿石阶向一层会客厅汇聚。
阳光穿透拱形玻璃窗，长桌擦得雪亮，摆着十三份热气腾腾的早餐——煎蛋、焦脆吐司、温牛奶，还有一小碟深沉琥珀色的自制果酱。大家各自握着手机，屏幕上清晰显示着洋宅立体地图与作息表。
"呜哇……这手机里连平面图都有哎！"可可飞快划动屏幕，"地下一层是寝室監房，一层是会客厅、食堂、医务室、淋浴房……二层还有図書室和娱乐室？！等等，地下控制室和仓库怎么全标成黑色不可进入区域啊？"
"上面写着'非开放区域，擅入者禁闭两天'的说。"汉娜挺直腰背，优雅地切着煎蛋，"哼，粗鲁无礼的监禁者……不过至少伙食没有敷衍本小姐，这果酱还算勉强过关哇！"虽然嘴上挑剔，她切面包的手指却因紧张而微微泛白。
橘雪莉单手托腮，挂着无懈可击的甜美微笑："各位同居人，早上好呢♪。我是橘雪莉，学校悬疑研究会的特聘名侦探哦。如果大家在这座不可思议的牢屋敷里遭遇难解的事件或迷局，随时欢迎来找名侦探雪莉咨询呢♪～"她笑眯眯喝着红茶，水色眸子深处却隐隐闪烁着冷静理性的探究欲。
玛格坐在靠窗一侧，指尖漫不经心翻动着塔罗牌，狐狸般的美眸似笑非笑落在我身上："哎呀……艾玛亲从刚才起就一直在偷看我呢。难道是想让我用塔罗牌，替你占卜今天会不会遇到危险的邂逅吗～？"
安安抱着黑色速写本，极度蜷缩在最边角的阴影里，一言不发地飞快落笔，随后将本子推到我面前：《敬启：此方绝境囚困十三头胆小之徒。吾辈且设一赌：诸君之中，孰能率先勘破"此地当居几何"之谜？赌注为吾辈手头这卷未完之书稿。》我忍不住弯起嘴角，轻轻碰了碰她的笔尖："行啊。但要怎么判定我赢了？"她羽毛笔行云流水划下：《当汝终有一日，立于管理之使魔或黑幕之前，向其掷出此等绝问并获悉其终局之时——汝便胜却此局。》
晨光一寸一寸挪过长桌。桌尾最末端，希罗独自端坐，面前早茶一口没动，低头极轻极慢地转着胸前那支黑色钢笔。笔盖的黄铜接口磨得锃亮，像有人日复一日用指腹擦过同一位置。她没有抬头，也没有去看手机上的任何规则，整个人仿佛被包裹在坚不可摧的冰甲之中。
我忽然注意到她——没跟任何人说话，只是低着头转笔。晨光挪到她手边，把她的手背照得发白。她始终没有抬头去接那束光，像那光里有什么，是她不愿意认回来的。我从那杯凉掉的茶上，移开了目光。

# --------------------------------------------------
# S4　希罗，读的那支笔
# --------------------------------------------------
@node ch1_shiro
"咳咳！诸位，餐盘请放置在回收台，晨会到此结束！"管家平板的公事化声调打断了各怀心事的空气。希罗将钢笔仔细别回上衣内侧口袋，站起身时眼睫极轻微地颤了颤，随即如同一道寂静的影子独自朝地下阶梯走去。
早餐后，我本该往庭院走。可脚不听指挥，又折回了地下一层监房走廊。希罗的房门关着。我在门外站了两秒，敲了两下没有动静，第三下门从里面拉开——希罗站在门缝里，黑发披着，眼神却清醒得不像刚醒。
"……有事？""早安。刚才在会客厅，你一句话也没说。有点担心。""我在休息。谢谢。"门要合上。我那句"早安"卡在喉咙里，不甘心地追了一步："刚才在走廊和会客厅里，你一直在看窗外那片湖——"希罗按着门框的指节微微僵住，回过头看我，眼神平得像一潭结冰的水，可冰面底下有什么东西动了一下。"——你在看什么？"走廊里静默得很响。
希罗垂下眼，胸前口袋里那支钢笔反了一下光。我以为她要发火或关门，可她只是很轻地说："我没有在看外面的湖。"她转身把门合上，合拢的瞬间咬字很轻，像不是对我说，而是对某一个不在场的人："……她不喜欢那片湖。"

我不知道明天该先找谁，也不知道这座岛将来会发生什么。我只模糊地知道一件事——这第一天，"没有发生任何事"。而这句话本身，在这座牢屋敷里，往后许多年回想起来，竟是最奢侈的一句。我在那包香草茶的香气里渐渐睡去。窗外，守夜的那盏灯亮着，照着满院的星光，照着一屋又一屋沉睡的、还活着的、各自的秘密。
