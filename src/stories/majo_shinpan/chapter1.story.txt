# S1　岸边，没有下雨 —— 登岛与十三人点名
# --------------------------------------------------
@node s0_breakfast
船是铁皮的老渡轮，锈红的漆一块一块往下掉，发动机突突地喘，像一头跑不动、又不敢停的老牲口。船舷外是灰绿色的海，把船身摇得吱呀作响。我们一共十三个人，是被那个自称"管家"的身影，从一辆辆不提名字的车里接下，又推上这条船的。
管家站在跳板口，捧着一本染过色的册子，一个一个地念名字，声音不急不缓，像在念一封早就写好的信。
"……泽渡可可。"管家念道。
可可从人堆里蹦出来，半块面包还叼在嘴里，含糊不清地举手："人家在——诶等等！车上的防晒霜能带吗？……墨镜呢？墨镜总行吧。"
管家只回了一句："列在禁带清单里的，统一保管。"
可可噎住，悻悻地把面包啃完："好、好，全给你们收走，人家记着了。"人群里有人低低笑了一声，是这艘船上不多的几声笑之一。
我认得住几个名字：二阶堂希罗——黑色长发扬在风里，别在胸前的笔反着光；冰上梅露露——修女般的白衣，拎一只洗得发白的小行李箱，连声道谢，脆生生的；城崎诺亚——白发丝带束发，缀满画具的黑白裙，蹲在队伍末尾一张皱巴巴的纸上画着什么；橘雪莉——水色三股辫盘成环，侦探风衣，抱着一本封面磨破的厚本子；佐伯米莉亚——哥特萝莉装的漂亮女孩，话不多，可一开口，就该是一股老气横秋的大叔腔。
管家点名到最后，喊的是"樱羽艾玛"。"到。"我应声，往前迈了半步，鞋尖差点勾到前排的包带，"对不起——"可可回头冲我挤挤眼，我的脸莫名其妙地热了一下。
船靠岸，已是午后。岛的中央立着一面灰白的高墙，把一半的岛圈了进去，墙爬满藤蔓。好几个人几乎同时放慢了脚步——空气里那层薄薄的"没事的"，被一面墙戳破了。
"这个……是监狱吧。"不知是谁很小声地说了一句。没人应她，答案几乎写在墙上了。
管家领我们穿过窄巷，走向那座名为"牢屋敷"的哥特大宅。它地面层是极宽阔的玄关大厅，连接上层的楼梯长到仰头才能望见顶，过道望不见尽头，门无数。管家走在最前，脚步几乎没有声响："诸位的房间在楼下的监房，行李稍后由守卫搬送。今晚早些休息，明日清晨六时三十分，会客厅集合。"
是米莉亚第一个迈上台阶："……住的地方，收拾得干净就行。走吧。"她的声音很平，像一句早已对无数间牢房说过的话。我们沿着长长的楼梯一层层往下走，越走越暗，越走越深。身后那扇我们来时的铁门，在我看不到的地方，轻轻合拢了。

# --------------------------------------------------
# S2　地下的第一个黄昏 —— 香草茶与守夜
# --------------------------------------------------
@node ch1_night
监房在地下一层，靠东的一排。门都是新的，门牌手写，字迹软软糯糯。管家难得停下来多解释一句："原先这里是铁栅栏，近日才换成了木门。夜里落锁，诸位从门里进出——总好过，笼在栅栏里头。"
我推开门，桌角放着一只空杯子，和一小包用纸卷着的散装花叶。纸角压着软软的小字："《冰上梅露露，拜访——读，刚上岛，各屋都放了一包自己晒的香草茶。不合口味就告诉我，明天给你换别样的。睡个甜觉呀。》"
我去拧了拧对门希罗的门，门内桌上同样摆着那只杯子和同一包香草茶。我心里忽然软了一下——那个叫梅露露的女孩，挨着每一扇门，都悄悄放了一包茶，又悄悄离开，给每个人，都留了一句"睡个甜觉"。
夜间，守夜开始了。灯火暗下去，我躺在木板床上，听见很轻的脚步声，从走廊这头踱到那头，再踱回来。那不是人——人的脚步不会这么均匀。是守卫。掩着的门缝底下，掠过一道长而直的黑影，一步一停，像在确认每一扇门都还关着。
第二天清晨，走廊里那张写着"巡查辛苦♪——可我们也是会害怕的生物呀"的便条不见了。守夜，却真的悄悄地轻了下去。
那晚我睡得很浅。隔壁传来可可压低嗓子讲笑话的声音，再隔一间，有人轻轻哼一首歌，调子软软的，一遍一遍哄着走廊入睡。那首歌我后来听过很多很多遍，全岛都会哼，管它叫"幽灵歌"。
我翻了个身，只反复记着一句话——管家说，在这里，我们"可以把日子，过成任何愿意过的日子"。我不知道那是真的，还是一句让牢里的鸟安静下来的好听话。但我愿意，先试着相信它是真的。

# S3　晨间的会客厅，七条规矩 —— 早餐与 E02
# --------------------------------------------------
@node ch1_s3
清晨六时三十分，会客厅。长桌擦得雪亮，摆着十三份早餐，牛奶、煎蛋、烤得酥脆的面包，还有一小碟岛上自产的琥珀色果酱。
管家站在晨光里，把一张薄薄的纸展开念道："其一，早六时三十分钟，会客厅早餐；此后为放风时段——六时至十时、正午十二时至十五时、十七时至二十二时，其余须待在寝室内，门禁由守卫把持；其二，每日换下的衣物，请丢入淋浴房最里侧的衣物滑槽，周一由焚烧炉统一处理；其三，二十二时熄灯宵禁，熄灯后不得外出，亦不得交谈；其四，不得进入地下更深处那扇焊死的铁门之后；其五，不得翻越西侧围墙；其六，午间与傍晚可往図書室借阅，或到中庭活动；其七——若遇上任何'你们解决不了的事'，请在会客厅中央，敲响那只袖钟。我会到。"
长桌静了一瞬。可可第一个举手追问"解决不了的事"指啥，管家平平地回她："……算。只要是你一个人的话，不能解决的事。"
"那要是，人家解决不了，别人也解决不了的事呢？"可可穷追不舍。管家的目光在长桌上很慢地扫了一圈，声音很轻："那么——就是它们来解决的事了。"
那句话像一只落下后没被接住的针，掉在地板上，发出极细的一声响。
我数了数桌子：十三个人，正好坐满，可每个人之间却像隔着一个湖，谁也到不了对岸。玛格捻着不知哪来的塔罗牌，慢悠悠说"吵架是岛上最新鲜的娱乐，准了"。
安安抱着她的速写本凑过来，在桌角飞快写了一行字，推到我面前——《本座细数，此岛足有十三头胆小鬼。并设一赌：谁先寻得'要在此住几时'的答案，谁便胜。》她写完用笔尾点点纸面，歪头看我。开口，是不需要声音的——她常年用笔谈，从不当面开口说话。
晨光从落地窗泼进会客厅。我注意到桌尾的希罗，面前那杯早茶一口没动，只是低着头，慢慢转着那支钢笔。笔帽的地方有一圈磨得发亮的铜色，像是有谁日复一日用指腹擦过同一个位置。她始终没有抬头，像那束光里有什么，是她不愿意认回来的。
我从那杯凉掉的茶上，移开了目光。

# S4　希罗，读的那支笔 —— E03
# --------------------------------------------------
@node ch1_shiro
早餐后，我折回地下监房。希罗的门，关着。我敲了两下没有动静，第三下门从里面拉开——她站在门缝里，黑发披着，眼神却清醒得不像刚醒。
"……有事？""早安。刚才在上面，你一句话也没说，有点担心。""我在休息。谢谢。"门要合上。
我那句"早安"卡在喉咙里，不甘心地追了一步："你昨天在船上，一直在看海——"希罗按着门框的指节微微僵住。她回过头看我，眼神平得像一潭结冰的水，可冰面底下有什么东西动了一下。
"——你在看什么？"我问。走廊里静默得很响。
希罗垂下眼，胸前口袋里那支钢笔反了一下光。我以为她要发火或关门，可她只是很轻地说："我没有在看海。"她转身把门合上，合拢的瞬间，咬字很轻，像不是对我说，而是对某一个不在场的人，"……她不喜欢那片湖。"
我站在走廊里，愣住了。那句"她"——到底是谁？一个"不喜欢那片湖"的、从没在这条走廊里出现过的人。
下午，庭院里三五成群。希罗没跟任何人说话，一个人坐在会客厅门侧的长椅上，手里横放着那支钢笔，用指腹一点一点抚过笔杆，像在抚一件很旧很旧的东西。她低着头，刘海遮住了大半张脸。
那一刻我心里冒出一个不该有的念头：这支笔，是不是替她装着一个她没法放下、谁也没有见过的人？这个念头，后来在很久很久以后被证实了。只是证实的方式，不在我今天能想到的尽头。

# S5　三十杯茶，和一杯没人要的 —— E04
# --------------------------------------------------
@node ch1_meruru
午后，医务室里，旧水壶呼噜噜响着。她系着素色围裙，正在给我们泡茶："是香草茶，加了岛上的薄荷和一点点蜂蜜。可可酱等下还要跟亚里沙酱拌嘴呢，喝甜一点，心情会好哦。"
梅露露的笑声脆生生的，像风铃。她挨个给我们续茶，轮到希罗时，希罗只接过去，端在手里，没喝。梅露露没追问，只是把杯沿朝她转了半圈："希罗酱，握这里，不烫。"希罗的动作顿了一下，很轻地"嗯"了一声，把那杯茶接得更稳了些。
我端着茶看着这一幕，忽然想：梅露露像是把岛上每个人"漏水的地方"都仔仔细细看了一遍。可有那么一个人，是她的那份好递不过去的——那个人，是玛格。
玛格坐在最靠窗的矮凳上，捻着牌，像没在听一屋子动静。梅露露端着热茶蹲到她身边，声音放得很软："玛格酱，这一杯我少放了些蜂蜜——你上次说太甜了，我记得。趁热喝吧。"
窗边空气静了一瞬。玛格没有回头，过了好几秒才开口："……谁跟你说，我不爱吃甜的。"
"你上次在我屋里亲口说的呀。"梅露露说得理所当然，"你还说'甜的东西会把心事也捂化了'——所以我调淡了一点，给你留着心思，不好吗？"
玛格终于转过头来，那双一贯漫不经心的眼睛里有什么东西尖锐地闪了一下。"梅露露，你这个人……"她没把话说完，站起来，把那杯茶轻轻推回梅露露手边，"……我不喝别人替我惦记的茶。好意这种东西，会越滚越大，最后把你整个人都吞了。你趁早收着点，别谁都递。"
屋里安静得有些僵硬。梅露露端着被推回来的茶愣在原地，两秒后"啊"了一声，柔柔地笑笑，把茶端回水壶边倒掉："玛格酱的茶，要留着，下次再泡。"
傍晚，我透过半掩的窗看见梅露露背对着门站在窗前，手里端着那杯被玛格推回来的茶。她没有倒掉，就那样端着，对着窗外那片暗下去的湖，静静地看。晚风吹起她额前的一缕碎发，她的侧脸安静得，像一幅还没来得及落泪的画。

# S6　墙根下，一颗没吹起来的气球 —— E05
# --------------------------------------------------
@node ch1_noah
日头偏西，庭院尽头的墙根拉出长长的影子。诺亚蹲在墙下，捏着一截不知哪捡来的粉笔，一笔一笔在墙上画一颗气球——圆圆的，鼓鼓的。这笔触其实有点笨：弧度收得不稳，手一抖就会出界，她却固执地一点一点描，像是生怕画得不够好，又像是生怕画得太好。
"……好看吗？"她没回头，声音很低。"好看，"我说，"比它旁边那几道发直的线强多了。"那是我能想到的、最不伤她的一句真话——因为那几道线，真的是她手抖画坏的。
"～它的手呢？"她还是没回头，粉笔尖停在气球下面那片空白，"气球的绳，得有手牵着。不然它飞上天，没人接，会飘到——没有名字的地方去。"
我静静站着。就在这时，背后传来轻微脚步声，是蕾雅。她停在几步外的草地边，像被什么牵住似的看着诺亚的背影，没有走近，只在原地有点局促地拢了拢头发——那副样子我认得，是那种"想靠近，又怕惊动"的神情。
她站了很久，末了从口袋里掏出一小卷叠得平平的、干净的纸，轻轻放在草坪边沿那块砖上，然后像怕被人看见似的，转身快步走开了。
诺亚的笔停了。她偏过头，看向那块砖上的纸卷，看了很久很久。"……给没有的手，"她低声说，"……留的。"她没有去拿，只是低下头，在气球旁边多画了一笔——一根从小纸卷里伸出来的、看不真切的手，线条很轻，像连她自己都不确定那算不算一只手。
我没有揭穿她，只在夜风里把那卷纸的位置记进心里。夜色把整面墙盖住。经过那块砖时，诺亚停了一瞬，然后弯下腰，把那卷纸捡起来揣进怀里，没拆。"～谨慎的美德，"她嘀咕了一句，"……先记着。"
我目送她的背影消失在暮色里，低头看见墙角还留着那颗气球的影子——圆圆的一圈，像一只还没来得及被吹起来的气。

晚餐，我端着盘子坐进人群。可可正手舞足蹈讲"墨镜被没收"的笑话，满桌人都被她逗得东倒西歪——除了玛格，她捻着牌嘴角似笑非笑；还有希罗，低头把番茄切成均匀的小块，认真得像在完成什么精密的工作。
饭后我路过走廊，蕾雅果然一个人站在窗边，看着楼下被路灯照亮的草坪。"……今晚，星星好多呀。"她站到我旁边，"我以前在很高的地方工作，每天都有很多人在看我。眼睛多的时候，你会忘记——原来星星，是可以一个人数的。"她说到一半大约自己觉得失言，立刻住口，换上客气的笑："啊，我瞎说的，别当真。"
我没有追问，只是陪她安安静静数了一小会儿星星，却把这句话悄悄记进了心里：眼睛多的时候，人会忘记，星星是可以一个人数的。
入夜熄灯。我躺在新换的木门后面，手里捏着梅露露那包香草茶的纸。走廊那边，又传来那道人人都会哼的"幽灵歌"的调子："家，我们走吧——窗，还没有关——"。哼的人是谁，我竟一时没听出来——岛上会哼它的人，已经不止一个了。
我闭上眼。白天的事一幕一幕晃：希罗那句"她不喜欢那片湖"、玛格那句"好意会把你吞了"、诺亚那颗没有手的气球、蕾雅那句"星星可以一个人数"、安安写下的那句"十三头胆小鬼"。
我不知道明天先找谁，也不知道这座岛将来会发生什么。我只模糊知道一件事——这第一天，"没有发生任何事"。而这句话本身，在这座岛上，往后许多年回想起来，竟是最奢侈的一句。
