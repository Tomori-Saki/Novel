# S1　第二天，从一盏坏掉的灯开始 —— E07
# --------------------------------------------------
@node ch2_s0_router
我醒在岛上第二个清晨。昨天夜里我躺在木门后面，睁着眼睛想了很久，把白天那些理不清的话一件件翻出来：希罗那句"她不喜欢那片海"、玛格那句"好意会把你吞了"、诺亚那颗没手的气球、蕾雅那句"星星可以一个人数"。
最后我是被走廊尽头一声不轻不响的"哐"惊回神的。我下到一楼，循声拐过拐角——走廊尽头那盏常年亮着的壁灯碎了，玻璃碴散了一地。一个矮小的身影蹲在那里收拾，是汉娜。她手里捏着一块碎玻璃，踮着脚想把灯口转回原位，够不着，急得鼻尖冒汗。
"……你要帮忙吗？"汉娜吓了一跳，回头看见我，用手背蹭了一下，"啊、没事！我……我想关它。这盏灯昨晚一直闪，整条走廊就像有什么在一下一下敲灯。我想换一盏不闪的，手一抖，就——打碎了。"
我蹲下来把大块的碎玻璃拢到一处："别急着转回去。你先去叫管家，就说'西侧走廊的壁灯坏了'。剩下收拾的，我来。"
"……可是让管家知道是我打碎的，会不会罚我？""它本来就坏了。你只是'想要修好它'的那个。管家认得出来。"
早餐时我把经过跟管家说了，管家只平静地"嗯"了一声："那盏灯前几日就一直闪，早该换了。"它没有罚谁。汉娜深呼一口气，坐回桌边，小声说了句"谢谢"。她大概是岛上第一个，因为一支坏掉的灯，被我记住名字的人。

# S2　守夜记事，和一支写不完的名字 —— E08
# --------------------------------------------------
@node ch2_shirili
午前我终于逮到机会单独碰见雪莉。她戴着那副窄边眼镜，那本厚本子摊在膝上，封皮磨得卷边。见我靠近她没合上本子，只拿手虚虚护了护摊开那页。
"……写了这么多，你在看什么？""岛上的事。谁住哪间房，谁几天爱做什么，哪扇窗朝哪面开……我都会记。"
"为什么记这些？你是想躲开谁？"她抬眼看了我一眼又垂下："不是躲，是为了'记得'。我爸以前说过——'人若是把日子过得糊涂，就会把对自己重要的东西也一并过了身。'……我怕我也有一天，把什么重要的东西过没了。"
阅览室很安静。雪莉翻到本子里夹着的一页松脱的纸，上面的字迹和刚才见到的不太一样，更像另一个人的手笔。纸角露出两个字的一角——"观者"。我轻声问，她犹豫片刻，缓缓把它转过来让我看全——那是一段像是从某本旧书抄下来的话："……观者即见证者。岛上一切'发生'，若无观者记下，便如未曾发生过。故，惟记下它的人，方能留住它。"
下面还有一行很小的、笔迹不同的字：《合雪案——谨记：遇雪，勿近，勿言，勿视。惟远处记之。》
旁边那个被墨水晕开的名字，被后来人轻轻地补成了一个字：雪。
我看到那个字心头猛地一跳。"雪莉，"我压低了声音，"这个'雪'——是这座岛上以前住过的人吗？"
雪莉没有立刻回答，她把那页纸重新夹进本子合上抱在怀里，末了只说了五个字："……我不知道。"她抬起头，透过镜片看我，"我只知道这本子是旧馆藏书堆里'本来就有的'。是上一位住在这里的人留下来的。艾玛同学，那句话——'勿近，勿言，勿视'——我是抄它的人，不是写它的人。"
那个字，像一根极细的看不见的线，从雪莉那本本子里，一路轻轻牵到了我心里。
晚上守夜。我躺着，想起一件事，披衣起来透过门缝往外看——走廊深处的窗边，希罗一个人站着，背对着我，手里捧着那支钢笔，笔尖悬在半空，像在写什么又久久没有落下。
我本要退回房里，却听见她极轻地，像对那个不存在的"她"开口："……你知道吗，今天，有人问起你了。"她顿了顿，"名字，被人念出来的时候，是会醒的。……可我还没想好，要不要让'你'醒。"
她把笔收进怀里，转身走进阴影。廊下的灯，在她经过时，忽地闪了一下。
我回到床上裹进被子，心口发紧，一直在想：那个"雪"，是被爱着的人，还是被记住就能让人后怕的名字？而希罗，到底是"放不下"她，还是——"不敢"放下她？

# S3　第二次递到窗边的茶 —— E09
# --------------------------------------------------
@node ch2_meruru
下午，我端着一杯自己泡好的热茶去梅露露的小屋。梅露露在屋外晒茶，见我端着茶来，先是一愣，随即笑起来："艾玛酱，这是……要替我泡茶？"
"算是回礼。你昨晚给我的香草茶很好喝。"梅露露接过去低头闻了闻，眼睛弯成两道月牙："……是柑橘皮和薄荷。你放的？比我会配。嗯——甜的，和昨晚你给可可那颗糖是一个味道。"
我耳根一热，我确实是顺着昨天想"她该也爱甜"的念头放了一点蜂蜜。她连这个都尝出来了。
"梅露露，昨天玛格那杯茶……你生气吗？"她端着杯子，过好一会儿才轻声说："不生气呀。我只是……有点不知道该怎么办。"
"怎么办？""玛格酱啊，"她的声音放得很轻，"她不是不喜欢甜，她是怕。你越是关心她，她越是往后退。你把热茶递过去，她接都不接，还要说'好意会把你吞了'。可她其实——不是不想要，是不敢要。她怕接了别人的好，就欠下、就还不清，就再也没法把自己裹起来当保护壳了。"
她顿了顿："我能看懂她的怕。可我越靠近，她退得越远；我又怕我不靠近，她就真的一个人裹着那层壳，冷死了。"
"那你明知道她那层壳，还去递那杯茶，是为什么？"梅露露低头，指尖在杯沿上轻轻转了一圈："因为——如果连我都因为她的壳就不递茶了，那这岛上，大概就真的没有人肯替她递一杯了。"她抬起头，"所以呀，那杯茶我会一直递下去。她推回来一次，我就在窗口多放一杯。她总有一天，会接住的。"
我没有告诉她——听完这句话，我心里第一个想到的，是希罗。

# S4　涂鸦墙，另一颗气球 —— E10
# --------------------------------------------------
@node ch2_noah
傍晚我又绕到旧墙根下。墙上多了一幅新画——不是气球，是一双手，五指张开，掌心朝上，像在接住什么从天而降的东西。画得不精细，线条有点犹疑，像一个第一次画"手"的人。
后面传来脚步声，回头是诺亚，手里捏着两截粉笔，一截白一截橘。"……你也来看画？那不是我画的。昨天，有人在我气球旁边，补了一只手。"
"蕾雅？"我脱口而出。诺亚没有否认也没有点头，只是又蹲下去，用那截橘色粉笔在那双手边上慢慢画了一颗新气球——和昨天那颗一样圆，只是这一次，气球的绳子终于牵在了那双摊开的手里。
"～她以为，接住我的笔，就是接住我了。"诺亚忽然说，"可气球的绳子，得两边都有手才栓得住。她那边，只有她替我伸出来的那一只。我这边……我还不敢。我怕牵住了，就再也收不回来了。"
她画完拍拍手站起来，把那截橘色粉笔揣进口袋。我站在墙下，看着那颗终于有手牵住的气球，心里却沉下去一块——蕾雅想接住诺亚，诺亚明明想要却不敢接。两个人之间隔着的不是距离，是一个"我能不能被接住/我敢不敢接住"的结。这个结我没法替他们解，甚至不知道该不该去碰它。

# S5　旧馆，地下之门 —— E11
# --------------------------------------------------
@node ch2_basement
第三天，变故是从一扇门开始的。午餐后我陪雪莉去旧馆一层还书，旧馆一楼尽头有一扇不起眼的铁门——平时都上着锁。可今天那扇门虚掩着，露出一道墨黑的门缝。
雪莉先注意到，脚步一顿，压低声音："……那是地下一层的门。"七条规矩里说"不得进入地下层"。"可它开着。"她说。
门缝里涌上来一股潮闷的气味，混着陈灰和一点点说不清的、陈旧的花木香。有人大概赶着送东西，忘了关。雪莉握着本子的指节微微泛白，我看得出来她想去——她是那种"既然记了就要弄明白"的人。
就在这时身后传来一个很轻的声音："别进去。"是奈叶香，她不知何时已站在我们几步外，抱着两本书，眼里的光不是害怕，而是更深的、克制的警示："规矩不是讲给怕它的人听的，是讲给'想知道它后面有什么'的人听的。关着的门能被看见，多半是因为，有人希望它被看见。"她顿了顿，语气淡得像在陈述天气："但看见，和走进，是两回事。"
风和日丽的走廊里，这句话让空气微微凝固。那扇铁门就在几步外，墨黑的门缝，像一个吞着许多陈年名字的、安静的嘴。

# S6　夜谈·胆小鬼也要伸手 —— E12
# --------------------------------------------------
@node ch2_night
夜里熄灯前的自由几分钟，安安抱着手稿神神秘秘拉我到走廊窗边："艾玛酱，你猜我今早起名字簿时候发现了什么？我们这座岛，是没有树的。"
"没有树……？""我数过了。樱花是温室墙根下的盆栽，围墙外是草，墙根是草，旧馆前后一棵正经的、立根土壤里的树都没有。可梅露露窗外那支野花，却是实打实从墙缝里长出来的。你想想——有人把一座岛打理得没有一棵树，是怕树影遮住什么？还是怕有人能在树上，做一个能看见全岛的梦？"
这话说得我没法接。我忽然想起那面灰白的高墙——也许正因为没有树，没有任何人能爬到比墙更高的地方，看墙外的东西。
"安安，你会不会想太多了。"她歪头用笔尾敲敲桌面，神秘莫测地："想太多的人，住不长。可这座岛上，谁又敢说自己不是想太多呢？——晚安啦，胆小鬼也是要伸手的。明天见。"
她抱着本子哼着"幽灵歌"一蹦一跳走了。我站在窗边看夜空，没有树，所以一整片天空都清清楚楚地压在一座岛上。星星很多，密得像盐。我想起蕾雅那晚说的"星星，是可以一个人数的"。而这岛上，有多少人正一个人数着自己的星星呢？
熄灯后我闭上眼，很久之后轻轻对自己说：明天，我该去见一见，那个一直把自己裹在壳里的人。
